# 🕹️ Retro Arcade

A browser-based retro arcade game collection featuring classic games built with HTML5 Canvas and vanilla JavaScript. No frameworks, no dependencies — just pure retro fun.

### Snake

The classic snake game. Use **Arrow Keys** or **WASD** to steer. Eat the pulsing pink food to grow and speed up. Survive as long as you can — your best score is saved locally.

**Controls:**
- **Arrow Keys** / **WASD** — Move
- **Space / Enter** — Start / Restart

## Getting Started

Open `index.html` in any modern browser. No build step, no server required — just double-click and play.

Or spin up a quick local server:

```bash
python -m http.server 8080
# then open http://localhost:8080
```

## Built With

- **HTML5 Canvas** — game rendering
- **Vanilla JavaScript** — game logic & audio
- **CSS3** — retro CRT aesthetic with scanline overlay and neon glow
- **Web Audio API** — chip-tune sound effects (square/sawtooth oscillators)
